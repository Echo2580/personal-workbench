1. 双击 start.cmd，进入首页再打开项目启动器，核对当前可见项目、已移除列表及配方。

3. 先体验终端键盘输入和停止，再验证目标项目的业务网页/外部服务；running 只表示进程存活。
4. 记录真人一行编辑耗时、真实项目业务就绪时间和自动配方正确率；与组员完成另一台电脑安装，开始两周真实使用记录。
5. 增量“从工作台移除 / 设置恢复”已加载到本机服务，刷新页面使用；目前没有代替你移除任何实际项目。运行中先停止，移除不删除本地文件，重扫/重启后保持隐藏。
6. 完成自己的代码评审后再提交、推送。当前所有改动仍未提交，原有 AI 交接文件保留。
