## 真实 Windows 行为

- 创建挂起进程、加入 Job 后恢复；创建/分配/恢复失败均验证清理。
- 父进程先退出而子进程仍在时维持 running；停止后树归零，外部同名 Python 对照进程保留。
- 真实 npm.cmd 运行测试脚本并创建 Node 后代；含中文、空格和 `&` 的 cwd 可用，停止后后代退出。
- 独立控制台通过真实键盘事件输入 `hello-console`，目标 `input()` 返回相同文本；不是 stdin PIPE 测试。
- 快速正常退出与非 0 退出区分；停止原因优先于强制终止码；重复/并发启动只创建一个运行。
- 终止隔离服务后 Job 子树退出，重启历史标记 interrupted，不接管旧 PID。
- 端口被占用会顺延，全部占用清晰失败；重复入口复用身份一致的实例。
- 停止失败时退出取消，服务保留；网页退出预览取消不影响运行。
- 另一次完整隔离冒烟已验证：关闭浏览器后服务和命令继续、重复入口复用、重新打开看到同一真实运行、网页停止与退出后服务返回 0。

这证明的是可控夹具的系统行为。Todo CLI 和狼人杀的真实业务交互留待使用者确认首次运行，不能由夹具替代。
