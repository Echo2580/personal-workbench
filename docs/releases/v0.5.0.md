# v0.5.0 — 识别扩展、首页个性化与数据根迁移

2026-10-19，部署目标为本仓库 `wb-stable` 工作树，日常端口 17843；准确源码版本以 annotated tag `v0.5.0` 为准。

## 变化

- **项目自动识别扩展**：Python 任意顶层 `main guard`、Django（`manage.py runserver`）、requirements+README 兜底；Node 脚本 dev > start > serve > preview，无脚本时按框架/main/单入口推断；Web 任意顶层 html（排除报告类），非 index 单页使用项目内 `.html` 静态 url；新增 Go（`go run`）与 Rust（`cargo run`）识别与项目页类型筛选。
- **首页个性化**：首页大字可编辑（Enter/失焦保存、Esc 取消、清空恢复默认，服务端偏好持久化）；右上角「我的空间」面板支持显示名/签名编辑、今日待办/笔记/项目概览、设置与退出。
- **待办**：新建待办提醒默认「不提醒」，可选「提前 N 分钟」（分钟数可自定义）或「指定提醒时间」；只填日期的截止时间不再被后端 422 拒绝。
- **数据根迁入项目内**：默认数据根从 `%LOCALAPPDATA%\PersonalWorkbench` 迁到 `<项目根>/data`（开发版 `wb\data`、稳定版 `wb-stable\data`），`--data-dir` / `WORKBENCH_DATA_DIR` 仍可覆盖；`.gitignore` 忽略 `/data/`，启动脚本、README、release 文档与识别基准工具同步更新。
- **文档与工具**：devlog/acceptance/spec/architecture 同步；新增只读 `tools/detection_report.py`。

## 验证

- 开发完整回归：**978 passed、4 skipped**（303.63s）。跳过项 = 真实模型默认关闭、两项依赖原截图项目源码/证据目录、Windows 非开发者模式无法创建符号链接 1 项。
- 识别真实目录样本（11 个非文档目录）：类型识别 8/11 → **11/11**；可执行自动主配方 7/11（63.6%）→ **9/11（81.8%）**；真实扫描根识别项目 10 → 25（详见 `docs/acceptance.md` 2026-10-18/19 条目）。
- 首页 UI（隔离实例 + Playwright）：1440/390 字号与布局、Enter/失焦/Esc、输入法 Enter、焦点不抢占、面板开关与视口内定位、偏好持久化均通过。
- 独立只读复核无阻塞项；其指出的弱边界、Go 无 main、报告 HTML 误报、失焦抢焦点、IME Enter 已修复并补回归。
- 迁移前备份稳定版数据至 `D:\AI实训project\个人工作台\数据备份\wb-stable-data-20261019-0042`（21 文件，业务文件 SHA-256 已记录）；迁移后冒烟（模块、项目、待办、偏好、数据哈希一致）记录在 tag 说明中。

## 数据与回滚

- 稳定版数据目录：`wb-stable\data`（旧的 `%LOCALAPPDATA%\PersonalWorkbench` 不再使用）。
- 升级前稳定版本：`v0.4.1 = 02b81b0`。回滚 = `git -C wb-stable reset --hard 02b81b0` + 重启，数据使用上述迁移前备份。
- 首次执行新的自动配方仍需按配方指纹确认；识别规则变化会让既有项目类型/配方发生变化（预期行为）。

## 已知限制

- 本机未安装 Go/Rust 工具链：Go/Rust 配方可识别、可通过模型与路径校验，但实际启动会提示缺程序。
- 识别弱边界修复只覆盖「扫描根目录」场景；嵌套目录中先命中的项目仍不继续拆子项目。
- 「我的空间」面板为非模态 popover（无 focus trap）；320px 以下视口未单独验证；首页大字对读屏仍暴露固定 `aria-label="我的一天"`。
- 提醒仅在工作台服务/页面运行期间生效，页面未打开时不会补发。
