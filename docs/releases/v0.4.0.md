# v0.4.0 — 全站深色工作台

2026-10-18 用户验收完成并授权提交 GitHub、迁移稳定版。发布目标为本仓库 `wb-stable` 工作树，日常端口 17843；准确源码版本以 annotated tag `v0.4.0` 为准。

## 变化

- 全站统一深墨绿/炭灰底色、浅黄绿主动作、左导航和紧凑卡片；覆盖首页、项目启动器、截图转待办、待办清单、设置及弹窗。
- 全局搜索由外壳管理，直接访问子页和刷新后支持搜索与 Ctrl+K；往返首页不重复监听或残留弹层。
- 自定义常用入口采用编辑草稿；取消、Escape、背景关闭均丢弃未保存修改，保存后正常持久化。
- 随手记纳入全局搜索；结果直接打开并聚焦对应笔记，同一结果可重复打开。旧版笔记具有稳定兼容 ID，异常文件结构不影响其他类别搜索。
- 相对 v0.3.0，本次同时发布 main 已有的真实常用入口、任务日程、随手记收集箱及设置页数据备份/恢复。

## 验证

- 开发完整回归：855 passed、3 skipped；专项回归16项包含在完整回归中。
- 补充用户功能场景18项通过，覆盖导入、核对保存、来源回看、任务操作、计划习惯、提醒、首页、备份恢复及错误恢复；页面脚本错误为空。
- 开发预览五个路由刷新后搜索、Ctrl+K及布局检查通过；独立代码复核无剩余阻塞项。
