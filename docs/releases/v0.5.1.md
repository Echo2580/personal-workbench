# v0.5.1 — 随手记查看全文/编辑与天气城市修复

2026-10-19，部署目标为本仓库 `wb-stable` 工作树，日常端口 17843；准确源码版本以 annotated tag `v0.5.1` 为准。

## 变化

- **随手记可查看完整内容**：首页卡片显示 2 行摘要；点击或「查看全文」打开详情弹窗，完整显示正文（保留换行/长串自动换行）与创建时间，支持复制全文、编辑保存（`PUT /api/v1/notes/{id}`，条数与 id 不变）、转待办、删除；「全部随手记」抽屉每条提供「查看全文」；搜索结果深链直接打开详情。
- **多行输入**：首页随手记改为自适应 textarea，Enter 保存、Shift+Enter 换行；输入法选词 Enter 不会误保存。
- **后端**：笔记保留换行与连续空格（不再折叠成一行），单条上限 500→1000 字，CRLF 统一、控制字符清理，旧 `notes.json` 与 legacy `lines` 兼容。
- **交互**：弹层按打开顺序置顶，Esc 只关最上层（抽屉→详情；编辑态 Esc 先回查看）；保存/关闭焦点恢复；多行笔记转待办标题折叠为单行；补齐本地 tailwind 缺失的文本工具类。
- **天气城市修复**（`0e62108`）：Open-Meteo 中文地理编码优先按「原名/原名+市」匹配与人口挑选，避免「洛阳」被福建洛阳镇带偏；中文索引缺失城市用 pypinyin 兜底；地理编码网络错误改报 `weather_unavailable`；`requirements.lock` 增加 `pypinyin==0.55.0`。

- 独立只读复核：发现的深链测试同步、叠层/Esc 顺序问题已修复并补回归。

## 数据与回滚

- 稳定版数据目录：`wb-stable\data`。
- 上一稳定版：`v0.5.0 = 0b5ec3e`。回滚 = `git -C wb-stable reset --hard 0b5ec3e` + 重启，数据使用迁移前备份（见 tag 说明）。
- 依赖：稳定版 venv 需同步 `requirements.lock`（新增 pypinyin）。

## 已知限制

- 单条笔记上限 1000 字；旧笔记中历史上已被折叠的换行无法恢复（文字内容不丢）。
- 详情编辑中点击遮罩会关闭并丢弃未保存修改（Esc 会先回到查看态）。
- 提醒/详情依赖工作台服务与页面运行；天气依赖 Open-Meteo，网络失败时显示不可用。
- 既有缺陷（非本次范围）：批量 `PUT /api/v1/notes` 调用了不存在的服务函数、`GET /notes` 重复注册，未在本次修复。
