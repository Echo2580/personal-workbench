# v0.5.2 — 待办删除确认弹窗

2026-10-19，部署目标为本仓库 `wb-stable` 工作树，日常端口 17843；准确源码版本以 annotated tag `v0.5.2` 为准。

## 变化

- **删除入口更直接**：待办清单每行右侧新增删除图标；详情头部新增删除图标；详情底部的「删除」按钮保留。三处入口打开同一个确认弹窗，不再需要滚到表单最下方找内联确认框。
- **确认弹窗**：使用原生 `<dialog>`，显示待办标题与「删除后不可恢复；来源记录会保留」提示；默认焦点在「取消」，避免回车误删；Esc、点击遮罩、取消均关闭且不删除；删除请求进行中禁止关闭。
- **删除反馈**：成功后关闭弹窗、提示「已删除待办」、列表/详情同步刷新，焦点回到「新建待办」；普通关闭后焦点回到触发按钮。失败时弹窗保留并在弹窗内显示错误，可直接重试。
- **可访问性与视觉**：`aria-labelledby` / `aria-describedby`、键盘可达、深色主题；1440 下 420px 居中弹窗，390×844 自适应无横向溢出；行删除图标默认不透明度 0.72（触屏 1），hover/focus 高亮为红色。
- **结构清理**：移除旧内联 `#delete-confirm`；列表行尾部改为独立删除按钮，避免 button 嵌套在链接内。
