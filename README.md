# 个人工作台

一个可以持续增加功能的 Windows 本机工作台：你缺什么，就往里加什么。默认进入工作台首页，通过统一导航打开功能。首个完整模块是“项目集中＋启动器”，让散落的练习项目重新回到手边。

## 安装与双击启动

需要 Windows、Python 3.12 或更高版本（安装时包含 Python Launcher）。本机验证环境为 Windows 11、Python 3.12.7。首次安装依赖需要联网，日常界面不依赖 CDN、在线字体或 Node 构建工具。

1. 将仓库放在自己的目录，双击 `install.cmd`。脚本只创建、使用本仓库的 `.venv`，按锁文件安装依赖。
2. 安装完成后双击 `start.cmd`，就绪后自动打开工作台首页。无需手工起 Uvicorn 或填写地址。
3. 在“设置 → 扫描目录”添加自己的目录。源代码默认目录为空，个人路径保存在本机数据目录。

也可在 PowerShell 安装：

```powershell
Set-Location -LiteralPath '你的仓库路径'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
.\start.cmd
```

`Bypass` 只用于这个 PowerShell 进程，不修改全局执行策略。开发与测试安装使用 `setup.ps1 -Development`；它额外安装 pytest、Playwright、Ruff 及测试浏览器。安装失败会保留真实错误，不继续报告成功。

## 首版功能

- 独立首页、统一导航、模块摘要、真实最近使用记录；快捷导航和待办日历标记为规划中。
- 只读扫描独立 Python、Node、静态网页项目；前后端分别列出，章节目录可手动添加。
- 搜索、类型筛选、排序、多配方、主配方、配方编辑抽屉、扫描与解释器设置。
- 项目卡片可“修改名称”并恢复默认；自定义名称在重扫、重启后保留，支持运行中改名。
- 项目卡片可“从工作台移除”，自动和手动项目均支持；重新扫描或重启后仍隐藏，可在设置中恢复。
- Python 使用项目 `.venv` → 用户默认解释器 → PATH / 基础 Python 的顺序，避免误用工作台自己的环境。
- 命令在独立 Windows 控制台运行，可输入键盘；Job Object 跟踪、停止本工作台创建的命令树。
- IDE、目录、网页属于“打开”动作，结果为“已请求打开”，不接管外部窗口。
- 首次或内容变化后展示完整命令、工作目录及目标，确认后才执行；相同内容以后可一键执行。
- 本地 TOML 保存、revision 冲突保护、原子替换及上一有效版本备份。

命令为 `running` 只表示进程仍存在，不代表 HTTP 或业务已就绪。命令输出和输入都在独立终端，不提供网页终端或历史输出回放。

关闭网页后，服务和项目继续运行；再次双击复用同一实例并打开首页。请在工作台中点“退出工作台”，确认后停止受管理任务再退出。停止失败时保留服务供重试。服务异常退出时 Job 句柄关闭会清理受管理进程，重启历史显示已中断，不按旧 PID 接管程序。

## 使用配方

自动识别只做静态分析，不运行 README、安装项目依赖、导入目标代码或读取密钥。Python 测试运行器不作为业务入口；多个业务入口仍要求人工选择。Node 优先 `dev`，其次 `start`；其他脚本通过配方编辑补充。

打开卡片中的“配方 → 编辑配方”，可以修改名称、类型、主配方和工作目录，添加或删除动作。原生命令可显式切换为一行 **Windows CMD** 命令；这里不是 PowerShell，命令前不使用 PowerShell 的 `&`。IDE 的参数按每行一项保存。运行中的命令配方不可修改；其他打开类配方仍可编辑。

自动扫描不会覆盖人工配方。保存冲突会保留草稿，请先核对外部编辑内容再重新打开合并。恢复自动识别只清除当前项目的人工覆盖。

卡片中的“从工作台移除”只影响工作台展示，不删除本地文件、数据库或环境，配方和历史也会保留。确认移除后，列表、首页数量和最近使用同步隐藏；重新扫描、重启不会自动添加回来。“设置 → 已移除项目”可恢复，恢复后按当前扫描目录或手动登记显示。运行中的项目需先停止；再次手动添加已移除目录会提示先恢复。移除只针对所选项目，不会连带隐藏其他独立项目。

默认扫描周期 15 秒、深度 5、目录预算 10000；不跟随目录符号链接或 junction，不进入虚拟环境、依赖、构建产物等排除目录。达到限制或遇到无权限目录会显示警告。根目录暂时不可用时保留旧结果。

## 自定义项目名称

点击项目卡片底部的“修改名称”，输入1–120个字符后保存，支持按 Enter 保存。名称去掉首尾空白，不接受空名称、换行或控制字符；配置冲突会保留输入。可点“恢复默认名称”，恢复目录名称或该手动项目最初登记的显示名称。

只修改工作台显示，不重命名磁盘目录、改变项目ID、配方、执行确认或运行进程。首页最近使用、搜索排序、移除列表与退出提示同步使用新名称。移除后恢复仍保留自定义名称，历史运行快照不被改写。

## 本地数据与排错

数据在 `%LOCALAPPDATA%\PersonalWorkbench\`：

| 路径 | 内容 |
|---|---|
| `settings.toml` | 目录、默认解释器、扫描选项 |
| `projects.toml` | 手动目录、人工配方、移除记录与自定义名称（按项目 ID） |
| `cache/projects.json` | 可重建扫描结果 |
| `history/projects.json` | 最近动作和运行历史，落盘最多 500 条 |
| `history/approvals.json` | 确认过的配方指纹 |
| `runtime/instance.json` | 当前实例身份与本地会话令牌 |
| `logs/service.log` | 服务日志，2 MiB 滚动，保留 3 份旧日志 |

不要将个人配置、历史、令牌或项目密钥提交到公共仓库。设置页可打开数据目录。TOML 解析失败时根据错误修复，或在确认退出后用相应 `.toml.bak` 恢复；损坏 JSON 需先备份再移开，由对应功能重建。该首版不自动覆盖损坏文件。

启动器仅绑定 `127.0.0.1`，在 17843–17852 中选择可用端口。全被占用时报告失败，不停止其他程序。无法启动时先检查日志、Python 版本和专用环境；重复双击不会创建第二份命令。实例记录丢失、过期或损坏时，入口会在候选端口内校验服务令牌、实例身份和数据目录，找回属于当前工作台的服务；不会仅凭端口打开或停止其他程序。已出现的旧错误弹窗需手动关闭，再运行 start.cmd；无需重装或清空个人配置。

## 开发与验证

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -Development
& .\.venv\Scripts\python.exe -m pytest tests\unit tests\integration tests\windows tests\browser -q
& .\.venv\Scripts\python.exe -m compileall -q app
& .\.venv\Scripts\python.exe -m ruff check app tests --select F,E9
& .\.venv\Scripts\python.exe -m pip check
```

开发服务：`& .\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 17843`。开发时请通过 `WORKBENCH_DATA_DIR` 指定隔离目录，不与日常服务同时操作同一配置。不要在有受管理运行时启用 reload；重载会结束相应 Job。
